# L_Shop - Online Coffee & Drinks Store

## 📋 Обзор проекта

L_Shop - это полнофункциональный интернет-магазин кофе и напитков с поддержкой:
- 🌍 **Локализация** (Русский, Английский, Испанский)
- ⭐ **Система рекомендаций** на основе тегов и лайков
- 👥 **Система ролей** (Guest, User, Owner, Manager)
- 🗣️ **Оценки и комментарии** для товаров
- 📦 **Управление товарами** для администраторов
- 🚀 **CI/CD** с GitHub Actions

## 🚀 Начало работы

### Требования
- Node.js 18+
- npm или yarn

### Установка

```bash
# Установка зависимостей на сервере
cd server
npm install

# Установка зависимостей на клиенте
cd ../client
npm install
```

### Запуск в режиме разработки

```bash
# Терминал 1: Запуск сервера
cd server
npm run dev

# Терминал 2: Запуск клиента
cd client
npm run dev
```

Откройте http://localhost:5173 в браузере.

### Сборка для продакшена

```bash
# Собрать сервер
cd server
npm run build

# Собрать клиент
cd client
npm run build
```

## 📚 Основные функции

### 1. Локализация (i18n)
- Выбор языка при первом посещении
- Сессионная кука (умирает при закрытии браузера)
- Поддержка 3 языков: русский, английский, испанский
- Автоматическое определение языка браузера

### 2. Система рекомендаций
- Теги для каждого товара
- Добавление тегов в рекомендации при лайке
- Встраивание рекомендаций в ленту
- Старение рекомендаций через 3 дня
- Подборка "часто просматриваемых" товаров

### 3. Оценки и комментарии
- Рейтинг от 1 до 5 звезд
- Комментарии (макс 500 символов)
- Видны только авторизованным пользователям
- Средняя оценка в карточке товара
- Дата комментария в формате DD.MM.YYYY HH:MM

### 4. Система ролей
- **Guest** - просмотр товаров
- **User** - покупки, оценки, комментарии
- **Manager** - создание и редактирование товаров
- **Owner** - полный контроль, назначение менеджеров

### 5. Admin Dashboard
- Страница доступна только для owner/manager
- Таблица с товарами
- Форма добавления/редактирования товаров
- Редактирование происходит на отдельной странице

## 🔌 API Endpoints

### Аутентификация
```
POST   /api/register           - Регистрация пользователя
POST   /api/login              - Вход в систему
GET    /api/me                 - Получить текущего пользователя
```

### Товары
```
GET    /api/products           - Получить все товары (с фильтрацией)
GET    /api/products/:id       - Получить товар по ID
POST   /api/admin/products     - Создать товар (owner/manager)
PUT    /api/admin/products/:id - Обновить товар (owner/manager)
DELETE /api/admin/products/:id - Удалить товар (owner only)
```

### Рейтинги
```
POST   /api/ratings            - Добавить рейтинг (auth)
GET    /api/ratings/:id        - Получить рейтинги товара
DELETE /api/ratings/:id        - Удалить рейтинг (owner comment)
```

### Локализация
```
GET    /api/locales?lang=en    - Получить файл локали
GET    /api/languages          - Получить доступные языки
```

### Корзина
```
GET    /api/cart               - Получить корзину (auth)
POST   /api/cart/add           - Добавить в корзину (auth)
PUT    /api/cart/update        - Обновить количество (auth)
DELETE /api/cart/remove        - Удалить из корзины (auth)
DELETE /api/cart/clear         - Очистить корзину (auth)
```

### Избранное
```
GET    /api/favorites          - Получить избранное (auth)
POST   /api/favorites/add      - Добавить в избранное (auth)
DELETE /api/favorites/remove   - Удалить из избранного (auth)
```

### Доставка
```
GET    /api/delivery           - История доставок (auth)
POST   /api/delivery/create    - Создать заказ (auth)
```
