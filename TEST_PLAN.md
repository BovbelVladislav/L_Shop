# План тестирования L_Shop

## Краткое описание
План покрытия основных функций приложения интернет-магазина тестами.

## 1. Локализация (i18n)

### Unit тесты
- ✅ Перевод текстов на разные языки (ru, en, es)
- ✅ Правильное определение языка браузера
- ✅ Сохранение выбранного языка в sessionStorage
- ✅ Сброс языка при закрытии сессии

### Integration тесты
- ✅ LocaleProvider работает правильно
- ✅ useLocale хук возвращает правильный язык
- ✅ Переключение языка обновляет текст на странице

## 2. Рекомендации

### Unit тесты
- ✅ Добавление тегов в рекомендации юзера
- ✅ Получение рекомендаций по тегам
- ✅ Старение рекомендаций (удаление старых за 3+ дней)
- ✅ Увеличение веса при повторном лайке

### Integration тесты
- ✅ Лайк товара добавляет его теги в рекомендации
- ✅ Рекомендации встраиваются в ленту продуктов

## 3. Система рейтингов и комментариев

### Unit тесты
- ✅ Добавление рейтинга (1-5 звезд)
- ✅ Валидация рейтинга (макс 500 символов комментария)
- ✅ Вычисление средней оценки
- ✅ Удаление рейтинга только автором
- ✅ Получение рейтингов по продукту

### Integration тесты
- ✅ Авторизованный пользователь может оставить отзыв
- ✅ Гость не может оставить отзыв
- ✅ Средняя оценка обновляется после добавления рейтинга
- ✅ Рейтинги отображаются в карточке товара

## 4. Система ролей (Owner, Manager)

### Unit тесты
- ✅ Создание продукта только owner/manager
- ✅ Редактирование продукта только owner/manager
- ✅ Удаление продукта только owner
- ✅ Назначение роли manager только owner-ом
- ✅ Сессия owner/manager умирает через 30 минут или при выходе

### Integration тесты
- ✅ Owner может создавать, редактировать, удалять товары
- ✅ Manager может создавать, редактировать товары (но не удалять)
- ✅ Guest не может никого изменять
- ✅ Admin страница недоступна для обычных пользователей

## 5. API endpoints

### Ratings
- POST /api/ratings - Добавить рейтинг
- GET /api/ratings/:id - Получить рейтинги продукта
- DELETE /api/ratings/:id - Удалить рейтинг

### Admin/Products
- POST /api/admin/products - Создать товар
- PUT /api/admin/products/:id - Обновить товар
- DELETE /api/admin/products/:id - Удалить товар

### Localization
- GET /api/locales?lang=en - Получить файл локали
- GET /api/languages - Получить список доступных языков

## 6. E2E (End-to-End) тесты

### User flow
- Регистрация пользователя
- Вход в систему
- Выбор языка
- Добавление товара в корзину
- Оставление отзыва
- Выполнение заказа

### Admin flow
- Вход админа
- Создание нового товара
- Редактирование товара
- Удаление товара
- Назначение менеджера

## 7. Инструменты тестирования
- Jest (unit & integration тесты)
- Supertest (API тесты)
- React Testing Library (компонент тесты)
- GitHub Actions (CI/CD)

## 8. Критерии покрытия
- Минимум 80% покрытия кода
- Все API endpoints протестированы
- Все критические user flows проверены
- Нет critical / high severity bugs
